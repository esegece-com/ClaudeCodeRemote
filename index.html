Claude Code Remote Help

Key Toolbar

The bottom toolbar provides keys commonly needed by Claude Code:

  • Esc — Cancel current operation
  • Tab — Accept suggestions / autocomplete
  • Intro — Enter / confirm input
  • Ctrl — Sticky modifier: tap once, then tap a letter (e.g. Ctrl+C to interrupt)
  • ↑ ↓ ← → — Navigate history and menus
  • Copy — Copy selected terminal text to clipboard
  • Clr — Clear terminal screen (Ctrl+L)

Copy & Paste

  • Copy: Select text in the terminal, then use Copy button or Ctrl+C (when text is selected)
  • Paste: Use Ctrl+V or your device's paste function

Sessions

Each session runs a separate Claude Code instance. Multiple users can join the same session to collaborate in real time. Session names are chosen at login.

Connection

If the connection drops, use Reconnect to auto-rejoin with saved credentials, or New Session to start fresh.

Keyboard Shortcuts

  • Ctrl+F — Search in terminal output
  • Escape — Close search bar
  • Ctrl+C — Copy selected text (or interrupt if nothing selected)
  • Ctrl+V — Paste from clipboard
  • Ctrl+/ — Show this help
